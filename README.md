# PDF 合并打印 · PDF Merge & Print

一个轻量的原生 macOS PDF 预览与拼版打印工具，解决系统打印面板无法选择每张纸打印 3、5 等奇数页的问题。

[隐私政策](PRIVACY.md) · [使用支持](SUPPORT.md) · [最小产品功能文档](docs/minimum-product-features.md)

## 功能

- 一次选择或拖入多个 PDF、图片或 Word 文档，统一查看与打印
- 图片会自动转换为单页 PDF；DOCX、DOC、RTF、RTFD 和 TXT 会通过 macOS 文本解析转换为 PDF
- 可为每份文件单独选择原始页面（如 `1,3,5-7`），按文件顺序合并选中页再统一排版、打印或导出
- 按文件名顺序组成连续页队列，无需先保存合并 PDF
- 原生文件列表：拖动排序、Option + 上下键移动、Delete 移除、右键菜单
- 文件添加、移除和排序可用 `⌘Z` 撤销、`⇧⌘Z` 重做，支持恢复已清空的队列
- 可折叠文件列表、可调整和隐藏的侧栏，小窗口中设置可滚动
- 标准 macOS 工具栏；预览刷新时保留画面，生成完成后再启用打印和导出
- 记住窗口大小和常用打印设置，中英文跟随系统语言
- 可命名保存多套打印方案，一键恢复每面页数、纸张、方向、排列、边距和边框；支持重命名和删除
- 每张纸单面可放 1-16 页，默认 3 页
- 可一键选择每面 1–6 页，也可直接输入任意 1–16 页
- 边距、边框与页码范围集中在“更多设置”，折叠时可查看自定义设置摘要
- 打印入口显示图标和文字；底部用两行展示打印结果，问号按钮解释单面、双面和系统布局设置
- 支持上下单列、左右单行和自动网格排列
- 支持 A4、A3、Letter 与横竖纸张方向
- 可对选中页面合并后的顺序进一步指定整体页码范围
- 可显示页面边框
- 调用 macOS 系统打印面板完成打印
- 可另存为已经拼版的 PDF
- 完全本地处理，不上传文件

## 使用

1. 选择一个或多个 PDF、图片或 Word 文档；多文件会按文件名顺序排列。
2. 点击每个文件下方的“全部 N 页”，选择全部或输入要使用的原始页码；再设置“每面放几页”、纸张方向与排列方式。
3. 在右侧检查打印预览。
4. 点击工具栏的打印图标，或按 `⌘P`。系统打印窗口中的“布局”保持“每张 1 页”，因为 App 已经完成拼版。

在“排版 → 打印方案”菜单中选择“存储当前设置…”即可保存常用排版。方案在下次启动时仍可使用；文件、页码范围和系统打印机设置不包含在方案内。调整设置后，菜单会显示匹配的方案名或“自定义设置”。

例如第一份 PDF 选 `1,3,5`、第二份选 `2-4`，右侧会按各文件原有页序预览共 6 页，默认每面 3 页，共输出 2 个打印面。改变任一文件的选页会将“更多设置”中的整体页码范围恢复为全部；撤销可恢复原来的选页和整体范围。原 PDF 视图仍显示完整原件，源文件不会被修改。

## 快捷键

- `⌘O`：添加文件
- `⌘Z` / `⇧⌘Z`：撤销 / 重做文件队列操作；在输入框内优先撤销 / 重做文字编辑
- `⌘P`：打印，`⌘S`：导出 PDF
- `⌥⌘S`：显示或隐藏侧栏
- `⌘1` / `⌘2`：原文档 / 打印预览
- `⌘+` / `⌘-` / `⌘0`：放大 / 缩小 / 适合窗口
- `⌘[` / `⌘]`：上一页 / 下一页
- 选中文件后，`⌥↑` / `⌥↓` 调整顺序，`Delete` 从当前队列移除（不会删除原文件）
- 选中文件后按 `Return` 或双击该文件可打开选页面板

## 系统要求

- macOS 13 或更高版本
- Apple 芯片或 Intel Mac

## 本地构建

需要安装 Xcode：

```bash
bash build.sh
```

构建结果位于 `dist.noindex/`。生成的 App 使用本机临时签名，适合本地使用；对外分发需要 Apple Developer ID 签名与公证。

## Mac App Store 构建

仓库包含 `PDFPinPrint.xcodeproj` 和应用沙盒配置。使用 Xcode 打开工程，在 Signing & Capabilities 中选择自己的开发团队，然后执行 Product > Archive。发布目标使用 Bundle ID `com.songningning.pdfpinprint`。

沙盒仅申请用户所选文件的读写权限与打印权限，PDF 内容仍完全在本机处理。

## 技术实现

使用 Swift、AppKit 与系统 PDFKit。拼版结果保持 PDF 矢量内容，不会先把页面转换为截图。
