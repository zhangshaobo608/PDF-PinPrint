## 描述

PDF拼印是一款轻量的原生 macOS PDF 预览与拼版打印工具，解决系统打印面板无法灵活选择每张纸放置 3 页、5 页等奇数页的问题。

你可以一次选择或拖入多个 PDF。应用会按文件名顺序组成连续页面队列，无需先保存合并文件，即可统一预览和打印。

主要功能：

- 每张纸单面放置 1–16 个 PDF 页面，默认 3 页
- 支持多个 PDF 连续拼版与批量打印
- 支持上下单列、左右单行和自动网格排列
- 支持 A4、A3、Letter 与横竖纸张方向
- 支持指定合并顺序中的打印页码范围
- 可显示 PDF 页面边框
- 可调用 macOS 系统打印面板完成打印
- 可另存为已经拼版的 PDF

PDF 内容完全在本机处理，不上传文件，不收集用户数据。

## 审核备注

PDF拼印无需账号登录、订阅或网络连接。所有 PDF 内容均在本地处理。

审核步骤：

1. 点击“选择多个 PDF…”，选择一个或多个本地 PDF。
2. 保持默认“每面 3 页”，查看右侧打印预览。
3. 点击“打印…”可打开 macOS 系统打印面板。
4. 点击“另存拼版 PDF…”可将结果保存到用户选择的位置。

当选择多个文件时，应用按文件名顺序将所有页面组成一个连续队列，不会在磁盘中创建临时合并文件。
