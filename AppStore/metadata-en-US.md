## Description

PDF Merge & Print is a lightweight native macOS utility for reading, combining, and printing PDFs. Place 3 pages, 5 pages, or any value from 1–16 on each printed side. Organize invoices, office documents, contracts, worksheets, handouts, exams, and reference material in one workflow.

Select or drop multiple PDFs to build a continuous page queue. Files are added in filename order; drag to rearrange them, add more, or remove individual files. View the original pages, check the print preview, and print or export without saving a temporary merged file first. Choose one page per sheet to output multiple PDFs as one file.

Keep layouts you use often. Save pages per sheet, paper size, orientation, arrangement, margins, and borders as a named print preset, then apply it next time. Rename or delete presets as your needs change. Undo and redo file additions, removals, and reordering, even after clearing the queue. Removing a file from the queue never deletes the original from your Mac.

Features:

- Place 1–16 pages on each printed side, with 3 as the default and quick choices for 1–6
- Combine multiple PDFs into a continuous layout for preview and batch printing
- Arrange pages in a vertical column, horizontal row, or automatic grid, including odd counts such as 3 and 5
- Choose A4, A3, or Letter paper, portrait or landscape, margins, and page borders
- Select page ranges from the combined page order
- Save named print presets that remain available after restarting the app
- Undo file changes with Command-Z and redo with Shift-Command-Z
- Use a native file list with drag reordering, keyboard controls, and a context menu
- Collapse the file list, resize or hide the sidebar, and scroll settings in smaller windows
- Switch between Original PDF and Print Preview, navigate thumbnails, zoom, or fit to the window
- Use the native macOS print dialog for printer and supported duplex settings
- Export an imposed PDF while preserving vector content
- Use English or Simplified Chinese based on your system language, on Apple silicon or Intel Macs

Workflow:

1. Click Add PDFs… or drop one or more PDFs into the window.
2. Check the Files list and drag to reorder. Use Command-Z to undo a file change.
3. Set pages per sheet, paper, orientation, and arrangement in Layout. Find margins, borders, and page ranges in More Settings.
4. To reuse a layout, choose Save Current Settings… from the Print preset menu.
5. Check Print Preview, then choose Print… or Export PDF….

The app has already arranged your pages, so keep Pages per Sheet set to 1 in the system print dialog. Presets do not include files, page ranges, or system printer settings.

All PDF processing stays on your Mac. No account, network connection, file uploads, or data collection. Requires macOS 13 or later.

## Review notes

Version 1.3.0, build 16. This native macOS PDF merge and multiple-pages-per-sheet utility is for office users, students, and teachers. It arranges local PDFs in order, with 1–16 pages per printed side, for invoices, documents, and handouts.

No account, login credentials, subscription, in-app purchase, or network connection is required. There is no hosted user-generated content, social functionality, or external content service. Core functionality uses Apple's AppKit, PDFKit, and macOS printing system. There are no third-party SDKs, cloud backends, payment providers, authentication services, or AI services. PDF content is processed locally and no data is collected.

Review steps:

1. Launch on a Mac running macOS 13 or later. Click Add PDFs… in the toolbar (Command-O) or Add PDFs… on the welcome screen. Choose at least two printable local PDFs. No special sample is required; any ordinary PDF documents can be used.
2. Inspect Print Preview with the default 3 pages per sheet. Choose 5 in Layout, or enter another count from 1–16. Pages flow continuously across files without forcing a new sheet for each file.
3. Drag files in the Files list to reorder, or select a file and use Option-Up/Down. Press Delete to remove a file from the queue, Command-Z to undo, and Shift-Command-Z to redo. Original files are not deleted. Removing all files can also be undone.
4. In Layout, open Print preset and choose Save Current Settings…. Enter a name and save. Change the layout, then choose the saved preset to restore it. The menu also supports Rename Preset… and Delete Preset…. Presets persist across app restarts and exclude files, page ranges, and system printer settings.
5. Expand More Settings to change margins, borders, or page ranges in the combined page order. The file list can be collapsed, and the sidebar scrolls to lower settings in a smaller window.
6. Click Print… (Command-P) to open the native print dialog. The pages are already composed, so keep the system Layout setting at 1 page per sheet. Choose a printer and its supported duplex options, or cancel to return. Click Export PDF… (Command-S) to save the composed PDF at a user-selected location.

Files selected together are initially added in filename order; users can then reorder them. The app does not create a temporary merged file on disk. Functionality is consistent across all regions; the interface uses English or Simplified Chinese according to the system language. The app does not operate in a regulated industry or supply protected third-party content. Users select their own local PDFs.
