## Description

PDF Merge & Print is a lightweight native macOS utility for combining PDF files into one print queue and printing multiple pages per sheet. It solves the common limitation in standard print dialogs that makes odd page counts such as 3 or 5 difficult to place on one sheet.

Select or drop multiple PDFs and the app builds one continuous page queue in filename order. There is no need to create a temporary merged file before previewing, printing, or exporting.

Features:

- Place 1–16 PDF pages on each sheet, with 3 as the default
- Process multiple PDFs as one continuous print queue
- Choose vertical, horizontal, or automatic grid arrangement
- Support A4, A3, and Letter paper in portrait or landscape orientation
- Print a selected page range from the merged order
- Show page borders in the preview, printout, and exported PDF
- Open the native macOS print dialog for printer and duplex settings
- Export an imposed PDF while preserving vector content
- Process all PDF content locally without uploads or data collection

## Review notes

PDF Merge & Print requires no account, subscription, or network connection. All PDF content is processed locally.

Review steps:

1. Click “Select Multiple PDFs…” and choose one or more local PDFs.
2. Keep the default 3 pages per sheet and inspect the Print Preview.
3. Click “Print…” to open the native macOS print dialog.
4. Click “Export imposed PDF…” to save the result to a location chosen by the user.

When multiple files are selected, the app processes every page in filename order and does not create a temporary merged file on disk.
