# 1.5.0 (22): native three-column workspace

Date: 2026-11-10 (Asia/Shanghai)

## Local delivery

The accepted interactive UI demo was implemented in the existing AppKit application. The universal local build was installed at `/Applications/PDF合并打印.app` for manual acceptance. Version 1.5.0 (22) was uploaded successfully on 2026-11-10 at 12:10 Asia/Shanghai; review submission is recorded separately in the release record.

Later on 2026-11-10, the local application, test copies, installer packages, archives, and build caches were moved to Trash at the user's request so future installs and updates use the App Store. Source files, original documents, preferences, and saved print presets were preserved. The verification below records the checks completed before that cleanup.

## Interface

- A resizable file sidebar, a central PDFKit preview, and a separate print inspector replace the combined file/settings sidebar.
- The file list fills the available height and scrolls independently. The Add Documents button and page-selection summary stay at its bottom.
- File rows use 66-point spacing, small thumbnails, a subtle accent selection, and contextual remove actions. Drag ordering, page selection, keyboard commands, context menus, and undo remain available.
- Paper, orientation, arrangement, and margins use compact inspector controls. Page borders and cut guides are visible without opening More Settings. The combined page range remains under More Settings.
- The inspector footer shows the single-sided paper estimate. The central footer retains output counts, page navigation, and print help.
- The toolbar includes application identity and independent controls for the file sidebar and inspector. Narrow windows automatically collapse the inspector; the inspector can be opened from the toolbar or with Option-Command-I.
- In original-document mode, selecting a file navigates to its first page in the combined original preview. Queue reloads do not trigger a user-selection callback.
- Colors and materials use native macOS semantic values, including system appearance and accent color. New labels are localized in English and Simplified Chinese.

## Verification

- Release compilation completed for arm64 and x86_64, followed by universal-binary assembly and code-signature verification.
- Installed and built executable hashes match. Application metadata, project settings, localization syntax, and whitespace checks passed.
- Actual application screenshots were inspected for the standard three-column layout and the compact layout with the inspector collapsed.
- A 15-file, 105-page queue was inspected in both layouts. File rows scroll within the available area while the Add Documents button and selection summary remain visible.
- A 21-page job produced 7 printing faces at 3 pages per face and 5 faces at 5 pages per face. Five pages remained in a single vertical column, with cut guides reaching both paper edges.
- Per-file selection of pages 2–4 changed the job from 21 to 17 pages. Undo restored the selection. Removing one 7-page file changed the job to 14 pages; the PDF preview remained visible with no empty-state overlay. Undo restored the file.
- No automated tests were added or run. No physical print job was sent.
