# PDF 合并打印｜最小产品功能文档

## 1. 产品定义

**产品名称**

- 中文：PDF 合并打印
- 英文：PDF Merge & Print

**一句话定位**

在 Mac 上把一份或多份 PDF、图片或 Word 文档转换为连续页面队列，按每面 1–16 页重新排版，然后直接预览、打印或导出。

**核心痛点**

macOS 系统打印面板通常只提供固定的偶数多页布局，用户无法方便地选择“每张纸 3 页、5 页”等排版方式，也无法在多份 PDF 中只挑选需要的页面后再统一打印。

**目标用户**

- 需要打印发票、合同、报销材料的办公用户
- 需要打印讲义、试卷、作业和阅读资料的教师与学生
- 需要把多份 PDF 组合后集中打印的个人用户

## 2. MVP 目标

用户从打开应用到拿到打印结果，应该只经过一条清晰路径：

1. 添加一个或多个本地 PDF、图片或 Word 文档。
2. 确认文件顺序，并按文件选择需要的页面。
3. 设置每面页数和纸张排版。
4. 在预览中确认结果。
5. 打印，或导出已经排版好的 PDF。

MVP 的成功标准是：用户不需要先用其他工具合并 PDF，也不需要在系统打印面板里再次设置多页排版。

## 3. 功能范围

### 3.1 P0：首版必须有

| 模块 | 功能 | 验收标准 |
| --- | --- | --- |
| 文件导入 | 选择或拖入 PDF、常见图片和 Word 文档 | PDF 原样读取；图片转为单页 PDF；DOCX、DOC、RTF、RTFD、TXT 转为 PDF；不支持的文件给出明确提示 |
| 文件队列 | 显示文件名、页数和当前可打印状态 | 文件列表能区分原始页数与选中页数；长文件名不会破坏布局 |
| 文件顺序 | 按文件名初始排序；拖动调整顺序；Option+上下移动 | 调整后右侧页面顺序立即更新 |
| 文件移除 | 删除当前文件，不影响磁盘原文件 | 删除后队列、页数、预览和打印结果同步更新 |
| 撤销恢复 | 撤销/重做添加、删除、排序和选页 | `⌘Z` 与 `⇧⌘Z` 能恢复前一步队列状态；清空后也可恢复 |
| 逐份选页 | 每份导入文件保留全部页面，或输入 `1,3,5-7` | 支持单页、连续范围、中文逗号和重复页码；非法或越界输入不可应用 |
| PDF 阅读 | 查看原 PDF 全部页面，支持缩放、适合窗口、缩略图和前后翻页 | 原 PDF 视图不因选页而隐藏源文件页面 |
| 排版设置 | 每面 1–16 页；快捷选择 1–6 页；默认 3 页 | 输入 3 或 5 后，预览和导出确实按对应数量排版 |
| 排版方向 | 自动网格、纵向单列、横向单行 | 3、5 等奇数数量不被强制补成偶数；自动网格按页面尺寸选择可读布局 |
| 纸张设置 | A4、A3、Letter；纵向/横向 | 页面尺寸和方向影响预览、打印和导出 |
| 边距与边框 | 标准、窄、宽边距；可显示页面边框 | 设置只影响排版页面周围区域；边框不改变源 PDF 内容 |
| 整体页码范围 | 对选页合并后的连续队列继续筛选页码 | 修改逐份选页后整体范围恢复为全部，避免旧页码指向错误页面 |
| 打印预览 | 在原 PDF 和打印预览之间切换 | 预览显示实际将要打印的页面、顺序、每面页数和纸张方向 |
| 打印 | 调用 macOS 原生打印面板 | 应用已经完成拼版；系统打印面板中的“每张页数”保持 1 |
| 导出 | 导出已经拼版的 PDF | 导出文件可被预览打开，页面顺序、矢量内容和边框设置正确 |
| 本地处理 | 不上传 PDF，不要求账号或网络 | 文件内容只在本机处理；原文件不被修改或删除 |
| 双语界面 | 简体中文和英语跟随系统语言 | 主要界面、错误提示、选页、预览、打印和导出流程均可用 |

### 3.2 P1：提升日常效率

这些功能不改变核心闭环，但已经适合纳入当前产品的完整体验：

- 保存、重命名和删除打印方案
- 记住窗口大小、侧栏状态和常用排版设置
- 折叠文件队列、隐藏或调整侧栏宽度
- `⌘O`、`⌘P`、`⌘S`、`⌘1`、`⌘2`、缩放和翻页快捷键
- 打印前显示页数、纸张、方向、每面页数和预计打印面数
- 对加密 PDF 请求密码；对禁止打印的 PDF 给出明确原因
- 打印预览生成期间保留上一份预览，并显示生成状态

## 4. 关键流程

### 4.1 首次打印

```text
打开应用
  ↓
选择或拖入 PDF、图片或 Word 文档
  ↓
确认文件顺序
  ↓
逐份选择全部页面或指定页面
  ↓
设置每面页数、纸张、方向、排列、边距和边框
  ↓
切换到打印预览
  ↓
打印或导出 PDF
```

### 4.2 多份文件的页面规则

- 文件按队列顺序处理。
- 每份文件先应用自己的页面选择。
- 所有选中页面再组成一个连续页面队列。
- 整体页码范围作用于这个连续队列。
- 原 PDF 视图始终显示完整源文件；打印预览、打印和导出只使用选中结果。

### 4.3 失败和恢复

- 文件无法读取：指出具体文件名，不影响其他文件的错误提示。
- 密码错误：允许重新输入，不把错误密码写入持久化设置。
- 文件禁止打印：在列表和生成结果中说明原因。
- 页面范围错误：说明允许的格式和页数上限，禁用“应用”。
- 排版过密：阻止生成，并提示调整每面页数、纸张或边距。
- 删除或排序误操作：可通过撤销恢复。

## 5. 非目标范围

以下能力不属于最小产品闭环，除非后续有明确需求，不纳入当前版本：

- 修改 PDF 正文、字体、图片或页面内容
- OCR、全文搜索、翻译和 AI 摘要
- PDF 签名、批注、表单填写和密码加密输出
- 云端同步、账号体系、团队协作和在线文件传输
- 移动端、Windows 端和 Web 端版本
- 自建打印机管理、打印机驱动和耗材管理
- 批量自动监控文件夹并自动打印
- 复杂装订、裁切线、出血线、书册装订和专业印前功能

## 6. 数据与隐私要求

- PDF 内容只保存在内存和用户主动选择的本地路径中。
- 应用不上传 PDF，不创建账号，不接入云端 PDF 服务。
- 删除队列项只移除当前任务引用，不删除用户原文件。
- 导出必须由用户选择目标路径，不覆盖源文件。
- 错误日志不得写入 PDF 正文、密码或文件内容。

## 7. 版本验收清单

发布前至少完成以下人工验收：

- 添加一份 PDF，验证原 PDF 阅读、3 页一面、打印预览和导出。
- 添加两份 PDF，验证文件顺序、拖动排序、删除和撤销恢复。
- 第一份选择 `1,3,5`，第二份选择 `2-4`，验证连续队列和总页数。
- 设置 5 页一面，验证页面按产品设定的纵向、横向或自动排列显示。
- 切换 A4/A3/Letter 和横纵方向，验证预览与导出纸张一致。
- 开启边框并调整边距，确认边框只显示在排版页面周围。
- 输入空值、重复页码、越界页码和反向范围，确认不能应用。
- 使用密码 PDF、禁止打印 PDF 和损坏 PDF，确认有针对性的提示。
- 在较小窗口中滚动侧栏，确认打印、导出和更多设置仍可访问。
- 切换简体中文和英语系统语言，确认核心流程没有未翻译文本。
- 打开 macOS 打印面板，确认系统“每张页数”保持 1，取消打印后能返回应用。

## 8. 产品边界判断

当用户能够在本机完成“多份 PDF 选页 → 合并排序 → 3/5/任意 1–16 页排版 → 预览 → 打印或导出”，产品就达到了最小可用标准。后续需求应优先服务这个闭环的稳定性、可理解性和重复使用效率，再考虑扩展 PDF 编辑能力。
