# 1.4.0 (17) - Per-File Page Selection

Date: 2026-09-18. Local application upgrade; App Store submission 1.3.0 (16) remains under review.

## Behavior

- Each PDF row opens a native page-selection sheet via its page count, Return, double-click, or context menu.
- Use all original pages or enter a comma-separated list and ranges such as `1,3,5-7`. Invalid and empty custom selections cannot be applied; duplicates are removed and original page order is preserved.
- The row and queue show selected and original totals. Selected pages flow across files into the same print preview, macOS print dialog, and exported PDF. Original PDF view continues to show all source pages.
- Changing a file's selection resets the combined page range to All, since merged page numbers change. Undo restores both the selection and the prior combined range. Moving or removing files retains their own selections in queue history.
- Both interface languages include the new controls and guidance. No account or network connection is involved; original PDFs are unchanged.
