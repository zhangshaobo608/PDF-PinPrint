# 1.2.0 (14) — 本地 UI 升级记录

日期：2026-09-17。此次交付为本地临时签名版本；未提交 App Store。

## 已实现

- 标准 `NSToolbar`：添加 PDF、预览模式、缩放、适合窗口、导出和打印。
- `NSSplitViewController` 侧栏：280–380 pt 宽度，可隐藏；最小窗口为 720 × 520 pt。
- 文件列表、排版、纸张与边框、打印范围分组；设置整体滚动，文件列表独立滚动并可折叠。
- `NSTableView` 文件队列：选中、拖动重排、外部 PDF 拖入、右键菜单、Option 上下键移动、Delete 移除。移除只改变当前任务，不删除磁盘文件。
- 刷新中保留上一版预览，显示状态提示，禁用打印与导出，结果完成后替换；过期异步结果按 revision 丢弃。
- 窗口尺寸和打印设置记忆；补充显示/窗口菜单、快捷键与中英文文案。

## 已完成的验证

- `bash build.sh`：arm64、x86_64 编译与通用二进制合并成功，临时签名验证成功。
- Xcode Release 构建成功（`CODE_SIGNING_ALLOWED=NO`）。本机 Xcode 报告设备/模拟器插件兼容提示，但未阻止 macOS 构建。
- plist、本地化文件、Xcode 工程语法检查通过，`git diff --check` 通过。
- 中文、英文运行界面均已打开检查。最终安装恢复跟随系统语言，当前显示中文。
- 两份示例 PDF 共 14 页，3 页一面生成 5 个打印面；5 页一面生成 3 个打印面，保持单列布局。
- 小窗口侧栏能滚动至边框和页码范围。
- 12 份示例 PDF 共 84 页能载入，文件列表保持有限高度并可折叠。
- Option 上下键可调整文件顺序；删除按钮和 Delete 可移除队列条目；最后一个条目移除后正确回到空状态，无引导文字叠加到预览的问题。
- 输入 0 等无效页数时保留上一版预览，显示错误提示，打印和导出禁用；恢复有效数值后重新启用。
- 导出示例 PDF 成功；系统打印面板正常打开，显示拼版后的页数及每张 1 页的系统布局，随后取消，未实际打印。
- 最终安装位置为 `/Applications/PDF拼印.app`，Info.plist 版本为 1.2.0 (14)。安装与构建二进制 SHA-256 一致：`7e29ae45b915756d7fb310526698e3d090d9d6e2c599772d41b4bab0afcf20ef`。
