# 1.3.0 (16) — 常用打印方案与撤销

日期：2026-09-17。本轮仅升级本地应用。

## 变化

- 在“排版”区新增“打印方案”：命名存储、应用、重命名、删除。保存每面页数、纸张、方向、排列、边距与边框；文件、页码范围和系统打印机设置不包含在方案内。
- 方案持久化在本机 UserDefaults，重启可用；输入名称时显示空名称、60 字符上限、重名校验。忽略损坏记录，保留其余有效方案。
- 编辑菜单新增撤销与重做（⌘Z / ⇧⌘Z），覆盖添加 PDF、删除及排序。最多保留 30 步文件操作，可撤销清空队列；退出应用后清除队列历史。
- 输入框优先使用文字编辑器的撤销历史。队列操作恢复文件顺序、选中项和当时的页码范围。
- 添加 PDF 时复用已载入的数据与密码，只读取新文件；相同路径重复添加不再重置队列和页码。
- 队列变更先构建源预览再写入可见状态与撤销历史，失败不会留下半更新状态。
- 同步中英文文案。
