# 1.2.1 (15) — 排版与视觉打磨

## 变化

- 核心设置集中到“排版”：常用每面 1–6 页、手动 1–16 页、纸张、方向、排列。
- 边距、边框、页码范围移入“更多设置”。折叠不会清空设置；自定义值显示摘要。记住用户明确选择的展开/折叠状态，页码输入错误时展开对应区域。

- 工具栏打印按钮显示图标及文字，缩放组和输出组增加间隔。
- 预览结果摘要精简为页数转换与纸张/方向/每面页数两行，翻页操作靠右。双面及系统每张页数说明移入问号帮助，导出成功提示按需显示。
- 字段标题采用次要文字色，区块标题更突出，间距统一为 8/12/16/24 pt。继续使用系统颜色与强调色。
- 新空状态：“合并 PDF，按需打印”，说明 1–16 页及本机处理；同步英文文案。
